# Portfolio Website

A premium, modular personal portfolio built with semantic HTML, CSS3, and vanilla JavaScript.

## Features
- Responsive hero, about, skills, projects, gallery, blog, and contact sections
- Glassmorphism styling with animated transitions and premium cursor
- Theme toggle with local storage memory
- Smooth scroll progress and reveal animations
- Interactive project and blog filters
- Contact form validation with feedback

## Structure
- HTML in index.html
- Styles in css/
- Scripts in js/
